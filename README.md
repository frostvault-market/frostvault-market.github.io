# FrostVault: خطوات التشغيل

**الخطوة 1 و 2 اتعملوا خلاص** على مشروعك في Supabase (قاعدة البيانات اتشغلت و `config.js` فيه بياناتك). ابدأ من الخطوة 3.

الملفات:
- `schema.sql`: قاعدة البيانات وقواعد الأمان. بتتشغل مرة واحدة في Supabase.
- `docs/`: الأبلكيشن نفسه (ويب أب). ده الفولدر اللي بيترفع على الاستضافة.

## 1. جهّز قاعدة البيانات
1. افتح مشروعك في Supabase.
2. من القائمة: SQL Editor، ثم New query.
3. انسخ كل محتوى `schema.sql` والصقه ودوس Run. لازم يطلع Success.

## 2. اربط الأبلكيشن بمشروعك
1. في Supabase: Project Settings ثم API.
2. انسخ الـ Project URL والـ anon key (ممكن يكون اسمه publishable key).
3. افتح `docs/config.js` وحطهم مكان `PASTE_PROJECT_URL` و `PASTE_ANON_KEY`.

مهم: متحطش الـ service_role key أو أي secret key في الملف ده أبدًا. اللي معاه المفتاح ده يقدر يعدّي كل قواعد الأمان.

## 3. ارفع الأبلكيشن
ارفع فولدر `docs/` على أي استضافة ملفات ثابتة مجانية (زي Netlify أو Cloudflare Pages أو GitHub Pages). هتاخد لينك https، وده اللينك اللي تبعته للناس.

بعدها في Supabase: Authentication ثم URL Configuration، وحط اللينك ده في Site URL، عشان إيميلات التأكيد ترجع المستخدم للأبلكيشن.

## 4. اعمل نفسك أدمن
1. افتح اللينك وسجّل حساب جديد بإيميلك.
2. ارجع لـ SQL Editor وشغّل السطر ده بعد ما تغيّر الإيميل:

```sql
update public.profiles set is_admin = true
 where id = (select id from auth.users where email = 'YOUR_EMAIL_HERE');
```

3. اعمل Refresh للأبلكيشن. هتلاقي زرار CREW PANEL في صفحة حسابك.

## 5. اظبط الإعدادات
من Crew panel ثم Settings:
- Buyer fee %: العمولة اللي بتتضاف على المشتري (الافتراضي 5).
- Seller fee %: العمولة اللي بتتخصم من البائع (الافتراضي 0).
- Hold days: مدة الحجز بعد ما المشتري يأكد (الافتراضي 3).
- Payment instructions: طريقة الدفع ليك (رقم المحفظة، عنوان USDT، إلخ). دي بتظهر للمشتري بعد ما يحجز.

## شغلك اليومي كأدمن
- Listings to review: افتح العرض، قارن الأرقام بالسكرين شوتس، ودوس APPROVE أو Reject.
- لما مشتري يحجز ويحوّلك: اتأكد إن المبلغ وصل فعلًا ومعاه الـ reference، وبعدين دوس CONFIRM PAYMENT RECEIVED.
- بعد ما فترة الحجز تخلص: حوّل للبائع نصيبه، وبعدين دوس RELEASE.
- في نزاع: اقرا الشات، وبعدين إما RELEASE للبائع أو Refund للمشتري (رجّع الفلوس الأول وبعدين دوس).

الأبلكيشن بيسجل الحالة بس. تحويل الفلوس نفسه بيحصل بره الأبلكيشن وبإيدك.

## تسطيبه على الموبايل
- أندرويد (Chrome): افتح اللينك، القائمة، ثم Add to Home screen.
- آيفون (Safari): افتح اللينك، زرار المشاركة، ثم Add to Home Screen.

## حاجات لازم تعرفها
- إيميلات التأكيد: الإرسال المجاني المدمج في Supabase محدود العدد. للتجربة ممكن تقفل Confirm email من Authentication ثم Providers ثم Email. للتشغيل الحقيقي اربط SMTP خاص بيك.
- مفيش "نسيت الباسورد" في النسخة دي. ممكن تبعت لينك استرجاع للمستخدم من لوحة Supabase (Authentication ثم Users).
- السكرين شوتس عامة: أي حد معاه لينك الصورة يشوفها. نبّه البائعين ميرفعوش صور فيها إيميل أو باسورد.
- الشات متخزن في قاعدة البيانات وإنت كأدمن بتشوفه كله.
- بيع الحسابات مخالف لشروط Century Games. الأبلكيشن بيوضح ده للمستخدمين، وهو مش تابع للعبة.
