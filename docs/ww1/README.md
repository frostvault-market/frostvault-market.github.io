# جبهة الكروت: الحرب العالمية الأولى

لعبة كروت للتليفون، 1 ضد 1 أونلاين أو ضد الكمبيوتر. بتشتغل من المتصفح، ومن "إضافة للشاشة الرئيسية" بتبقى زي أي أبلكيشن.

## الملفات
- `index.html` و `style.css`: الصفحة والشكل.
- `cards.js`: كل الكروت (الأرقام والقدرات والمعلومة التاريخية). عشان تعدّل التوازن غيّر الأرقام هنا.
- `engine.js`: قواعد اللعبة.
- `ai.js`: خصم التدريب.
- `game.js`: الشاشات والأونلاين.
- `peerjs.min.js`: مكتبة PeerJS (رخصة MIT) للاتصال المباشر بين التليفونين.

## الأونلاين
اللاعب الأول بيعمل أوضة وياخد كود من 5 حروف، والتاني بيكتبه. تليفون صاحب الأوضة هو اللي بيحسب المعركة، والتاني بيبعت حركاته بس.
اللعبة بتستخدم سيرفر PeerJS المجاني العام عشان الاتنين يلاقوا بعض. ده كويس للتجربة، بس مالوش ضمان.
لو اللعبة كبرت، الأحسن تعمل سيرفر خاص بيها.

العملات والكروت متسجلة على التليفون نفسه (localStorage)، فمسح بيانات المتصفح بيمسحها.
